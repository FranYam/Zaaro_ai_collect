# Réorganisation partielle : dossier `src/server/` pour le backend partagé

## Objectif
Regrouper la logique serveur (auth, Prisma, Supabase) dans `src/server/` pour rendre la séparation backend/frontend explicite — **sans toucher aux dossiers imposés par Next.js** (`app/api/**`, pages, `middleware.ts` à la racine). Zéro changement de comportement : uniquement des déplacements + imports.

## Déplacements (git mv, historique préservé)

| Fichier actuel | Destination |
|---|---|
| `auth.ts` (racine) | `src/server/auth.ts` |
| `auth.config.ts` (racine) | `src/server/auth.config.ts` |
| `src/lib/prisma.ts` | `src/server/prisma.ts` |
| `src/lib/supabase/admin.ts` | `src/server/supabase/admin.ts` |
| `src/lib/supabase/storage.ts` | `src/server/supabase/storage.ts` |

**Restent en place :**
- `middleware.ts` (racine) — exigence du framework ; son import sera mis à jour
- `src/lib/utils.ts` — utilisé par 5 composants UI (`cn()`), c'est du frontend
- `scripts/` — utilisent `@prisma/client` directement, non concernés

## Structure finale

```
src/
├── server/            ← BACKEND : auth, prisma, supabase (logique serveur)
├── lib/utils.ts       ← FRONTEND : helper cn()
├── components/        ← FRONTEND : composants UI
└── app/
    ├── api/           ← BACKEND : endpoints REST
    └── (app)/, (admin)/, login, register  ← FRONTEND : pages
middleware.ts          ← racine (contrainte Next.js), importe @/server/auth.config
```

## Vérification (votre exigence : zéro impact)
1. `grep` — zéro référence restante aux anciens chemins (`@/../auth`, `@/lib/prisma`, `@/lib/supabase`)
2. `npm run build` — TypeScript valide chaque import ; toute omission = erreur de build
3. **Smoke test réel** sur le serveur de dev : login admin → `GET /api/admin/recordings` (200 + données) → `GET /dashboard`, `/admin`, `/login` (200)
4. Uniquement si tout est vert : commit `refactor: move server logic into src/server`

## Risques couverts
- Le middleware (edge runtime) : `auth.config.ts` n'importe rien de Node → compatible edge après déplacement
- Pages `(app)` server components : imports mis à jour comme les autres
- `next build` + smoke test garantissent la non-régression avant tout commit
